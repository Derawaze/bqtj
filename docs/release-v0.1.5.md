# v0.1.5

- 修复加载游戏时切换窗口档位后，窗口变大但游戏画面仍保持原尺寸的问题；延迟初始化和后续脚本改写缩放属性后仍维护等比居中。
- 修复保存全屏档位后重新启动时，因最大化与首次显示禁止激活冲突而无法打开容器的问题。
- 原生 Flash 宿主开启大地址支持，扩大可用虚拟地址空间；构建时检查 x86 架构及大地址标志。
- 改进刷新时旧浏览器/Flash 实例的释放，恢复命令超时后的后续请求，减少刷新被旧请求阻塞的问题。
- 取消固定四账号多开上限，同一账号仍只打开一个游戏窗口；多开数量由用户按电脑资源选择。
- 移除游戏容器上的“账号密码”按钮及专用弹窗，账号管理留在面板，保存凭据的自动登录保留。

## 使用

完整解压 ZIP 后运行 BqtjLauncher.Desktop.exe，两个 EXE 必须放在同一目录。已含 .NET，无需另装 .NET 运行库；游戏仍需本机注册 32 位 Flash ActiveX。账号密码按用户选择明文保存在本机。原生迁移原型和 Maa 功能不包含在此版本中。
