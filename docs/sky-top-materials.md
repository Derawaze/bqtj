# 天空顶每日材料

2026-10-23，用户确认开发包20261023132532可作为初代可用版本。每日限额识别仍需改进；待办统一见[任务清单](backlog.md)，具体故障原因和回归入口见[回归要点](regressions.md)。本页只维护当前流程，不保留逐轮开发包记录。

## 入口与执行身份

当前只支持寒光市－天空顶－正常模式，默认地狱四。中文语句可继承前一条操作的账号/存档，也可显式指定：

```text
启动存档,示例主号,存档5
刷取每日材料,天空顶,地狱四,刷满
刷取每日材料,示例主号,存档5,天空顶,地狱四,8次
```

支持简单、普通、困难、超难、冲刺、炼狱、地狱、地狱二、地狱三、地狱四。未知地图、难度或次数在游戏操作前拒绝。固定次数完成后退出关卡、确认并关闭评价，回到城镇；刷满也走相同退出流程。

账号由稳定ID绑定，每账号独占会话控制权，同账号多存档串行，不同账号可显式并行。接管已有窗口会确认指定存档；同次方案的同档操作直接复用。日常自行完成系统/侧栏收尾，刷关不替上一句清理页面。默认临时2倍速、950×600，结束或停止恢复用户偏好；窗口可以遮挡但不能最小化。

## 无总统：搜索与拾取

1. 等待自动战斗完成，先检查背包“满”标记，需要时整理后重新截图。
2. 首屏识别必需材料。刷满模式仅第10轮及以后、首屏没有材料时查限额；前9轮、有材料的轮次和固定次数模式不查，拾取后也不追加查询。
3. AI开启时同一次后台请求按N和W，50ms后松N，继续上升；原本关闭则不重复切换。先升到顶，再沿顶向右。小地图唯一黄点代表操控角色，绿点是队友；可靠黄点优先判断触边，否则参考上沿薄血条。
4. W累计上限1200ms、D累计上限3500ms，包含N/W同步首段；确认触边可以提前结束，预算耗尽也按到达继续。首个短按后及累计每360ms观察目标。人物可定位且看见必需材料时可提前进入局部拾取；人物被抽奖遮住时继续上/右，不盲目下移找血条。
5. 局部先靠近目标区域左上侧，再走右、下、左一轮，横向覆盖宽度为材料区域2.4倍，下降行距38。短按校准选择远离边界的一侧，保留已看到的目标，不能因一两帧漏读就当作捡完。
6. 结束连续两帧复查，间隔120ms；新材料显露则继续当前区域，最多补捡三次。仍有材料时保留窗口暂停。重新开启AI后重玩或按次数退出。

参数位于scripts/resources/loot/catalog.json的sweep，miniMap当前为(831,21,74,44)，最长短按180ms。黄点范围从波次文字下沿开始；血条最短23px，仍要求薄横条及唯一候选。参数属于本关适配，不能直接复制为其他地图默认路线。

## 目标与识别资源

| 类别 | 当前处理 |
|---|---|
| 冷冻宝石、守护宝石、冥王图鉴 | 本关必需材料 |
| 血石 | 辅助定位邻近掉落区，可顺带，不阻塞完成或增加限额条件 |
| 远古/传奇/稀有宝箱 | 全关卡顺带项，不专门绕路 |
| 武器、装备 | 可沿材料路线顺带拾取，不要求逐件清空 |
| 银币、商券、弹药箱、药瓶等 | 不进入本关目标清单 |

源码资源在resources/automation/sky-top，交付到scripts/resources/loot。catalog.json version=3按map＋purpose选择recognize/pickup，globalPickup只放全关卡顺带项，不汇总其他地图材料。本轮37张PNG及物品对应见[图标目录](../resources/automation/sky-top/README.md)。

匹配使用共享像素截图上的本体纹理与透明遮罩；Maa负责后台截图、OCR和底层控制，不是训练了新的物品识别模型。普通物品沿用背包图案，装备/武器使用战场图案；门槛0.88，不把品质光晕、雨线或邻居加入模板。冷冻宝石必须先匹配本体，青色晶面只扩展已确认的同一堆；装置和出口白光不能仅凭颜色成为目标。

与抽奖区域相交的模板候选排除。顶部暗栏同时有已发放奖品，过去出现过奖品误判；当前靠固定扫顶覆盖被挡物，不直接追踪暗栏图案。守护宝石/图鉴保留已确认的堆叠、重叠及小雨相位，匿名连续帧和天空/出口反例一起回放。大雨及所有遮挡组合尚未覆盖。

## 满包整理与共用菜单

背包入口ROI(50,515,60,50)明确出现独立“满”字才整理。打开背包后依次处理武器、装备：一键拆解、确认、确认结果。没有可拆物品也是正常结果；不修改用户的品质和保留条件。基因体标签正上方有“满”才切换并一键分解、确认，随后关闭背包继续拾取。

物品详情可能遮住分类或拆解按钮。每次观察背包分类、按钮及弹窗前，先后台悬停到标题(720,32)，重新截图后再读，分类切换和结果确认后同样处理，不占用系统鼠标。确认/结果由灰色面板和红色按钮布局区分，每50ms观察切换，不依赖“拆解完成”文字。

| 动作 | 950×600下位置 |
|---|---|
| 天空顶入口 | (676,444)，点击后观察正常模式页 |
| 难度 | 正常模式两列五行固定按钮；看到难度页才点击 |
| 重玩关卡 / 退出关卡 | (470,309) / (470,356) |
| 重玩、退出、拆解确认 | (420,315)，先确认对应弹窗 |
| 拆解结果确定 | (475,315) |
| 掉落查看悬停 | (160,488) |

正常模式首击无效时，仅按钮仍可见才有限重试，最多3次、间隔至少1秒；重玩确认后直接观察新画面，不等待抽奖消失或计时复位。重玩/退出和整理方法供后续同类关卡复用。

## 每日限额与账号权益

冷冻宝石/守护宝石共用上限，冥王图鉴另有上限；两项都有有效计数、达到或超过上限且呈绿色才确认刷满。未满为蓝色。名称与分离数字按同帧位置关联，小数字漏读时使用协议7同快照数字样式补读，颜色仍取原图，不跨行拼接。

最多四次重新悬停采样；原生组件在截图前及等待期间维持本窗口一秒短租期悬停，其他输入或释放目标即清除。鼠标在窗口外时弹层仍可能缺失，这一问题未宣告解决。读不到就收起系统，继续搜索和刷取；连续空屏、暗栏遮挡或估计掉落轮数都不作为上限。可使用固定次数模式控制运行轮数。

新增/编辑账号或账号工具可勾选“有总统（月卡）”，所有存档共用、默认关闭，运行冻结权益。总统通关后等真实时间约1秒自动拾取和拆解，不关AI、不走位、不打开背包；第10轮起每轮查限额，不要求首屏为空。到期/续费后手动更新，下次运行生效。TXT导入审核和启动时间回写保留已有权益。

## 模块、更新与验证边界

- DailyMaterialFarming管理轮数、查询时机和重玩，DailyMaterialQuota负责本关双限额解析；OfficialScriptExecutor.SkyTop适配菜单与战后流程。
- SkyTopFixedSweep负责本关边界、路线和局部目标；SkyTopSceneVision/SkyTopMiniMap负责HUD与黄点，SkyTopDropVision加载按关卡选择的资源快照。
- OfficialScriptExecutor.Battle/Inventory保留共用菜单、退出和整理；旧分组路线与镜头配准保留为诊断参考，不接回当前拾取入口。
- 只更新已支持的方案、图片及规则可合并scripts资源包；新地图流程、语法或底层能力仍可能需要更新主程序/组件。覆盖保留用户plans、config、catalog和自定义脚本，运行中任务不会热替换快照。
- 回归使用虚构账号、匿名物品/HUD/弹窗裁剪。完整战场、背包、OCR和运行现场只留在忽略的artifacts/dev，不能提交或交付。
- 用户认可初代可用；限额识别、总统真实账号、大雨、其他出生点和多账号长期并行仍有覆盖缺口。不得将合成点击、静态图案命中或CI通过写成这些场景已验收。
