# v0.1.2

本版包含游戏资源动态解析修复，以及入口校验、开发预览和发布流程改进。

- 每次启动读取平台当前游戏版本，失败时回退缓存或随包入口。
- 限定本游戏资源目录，跳过无关iframe并处理地址转义；缓存不标记为平台最新。
- 保留账号管理、自动登录、多账号并行、窗口缩放、静音与变速。
- 开发模式支持保存后自动构建并重启自有预览窗口；提供只读内存采样工具。
- GitHub Actions自动测试、构建Windows x86压缩包并发布ZIP及SHA256。

## 使用

下载ZIP，完整解压后运行 BqtjLauncher.Desktop.exe。两个EXE必须放在同一目录。
已包含.NET运行库，游戏仍需本机已注册的32位Flash ActiveX。账号密码按用户选择明文保存在本机。

## 已知限制

- 已修复Flash的NoScale/左上对齐导致150%内容不放大；现场校准及离线回归通过，战斗点击和跨屏尚未验证。
- 加载期间蓝色闪帧未确认完全消除。
- 不承诺Flash全部本地存储隔离；关闭游戏后登录态不持久化，可用已保存凭据重新登录。
- 原生Flash无法保留关卡状态热替换；开发自动重启会中断游戏。

测试和构建结果以本标签对应的GitHub Actions记录为准；自动测试不替代真实游戏验收。
