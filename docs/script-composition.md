# 中文语句与可组合脚本设计

状态：2026-10-17第一版已实现，开发包待用户验收。支持中文语句、常量、子方案调用和显式并行；用户已确认并行块、窗口复用及改名可选同步全部引用。v1方案仍按原语义运行。

## 目标与术语

编辑内容与运行实例明确分开；用户可用中文语句组织启动器提供的操作，把一组操作保存为子方案，在其他方案中插入调用后一键运行。首批能力围绕现有日常流程，不扩大为通用编程语言。

| 对象 | 职责 |
|---|---|
| 游戏内置脚本 | 游戏自己执行的“日常操作复制”等流程，最终冷却及保存仍由游戏处理 |
| 启动器操作 | 本项目封装的一条可插入语句，例如日常操作、读取存档名称、启动存档、退出存档、关闭窗口 |
| 脚本方案 | 可编辑、保存和运行的一组语句与账号/存档绑定 |
| 子方案 | 被其他方案调用的已保存方案；同一对象可独立运行，也可作为可复用步骤 |
| 常量 | 有名字的固定值或账号/存档绑定，例如主号、日常一、日常二；不是账号密码 |
| 运行实例 | 启动时冻结的方案、子方案和参数快照，以及本轮执行进度 |

不再把“函数”作为另一种必须学习的文件类型。先用可调用的子方案覆盖复用需求，再按实际需要增加账号/存档参数；不同时引入函数声明、返回值、循环和任意表达式。

## 界面建议

保留独立脚本管理窗口，左侧合并显示所有方案，内置名称标记“（内置模板）”；中间语句、右侧可插入命令。双击命令插入，双击方案或编辑区进入编辑。编辑按钮位于底部校验按钮左侧，上方不设运行监控或重命名按钮。保存后右侧命令栏隐藏并切换运行监控，中间显示只读已保存语句；点击“编辑方案”恢复编辑和命令栏。运行状态不混入可编辑正文。

| 方案编辑左栏 | 方案编辑中栏 | 方案编辑右栏 |
|---|---|---|
| 统一方案列表、内置模板、搜索 | 方案名、带行号的语句编辑器 | 启动器操作、我的子方案、常量与参数 |
| 新建、复制方案、删除 | 关键字高亮、参数补全、行内错误 | 搜索操作、填写账号/存档参数、插入光标处 |
| 内置模板和普通方案统一保存，可编辑或复制 | 保存、校验、运行 | 简短说明、运行前提、完成后的界面 |

- “日常操作复制”等名称显式展示；后台窗口可遮挡、不能最小化的提醒保持可见。
- 内置模板不绑定开发者真实账号。它们与用户方案共同保存在plans，使用固定ID及.built-ins-v1/.built-ins-v2标记；单账号/并行模板采用用户编辑的例子，新增全局常量示例，读取名称模板退役。可直接编辑或删除，升级保留自定义内容；设置和日常操作定义写在注释里。右侧“子方案”仍可调用隐藏于主面板的方案。
- 编辑区的执行预览属于草稿，不称为运行队列。运行监控只读，显示运行方案/快照、账号、存档、当前语句、状态和原因，停止入口只作用于本次运行。
- 编辑时右下角仅显示插入语句，监控时同位置显示停止；运行期间编辑草稿，需要停止时保存草稿回到运行监控，错误草稿也允许保存。错误草稿允许保存，运行才强制校验；不让校验结果阻止记录未完成语句。用户可以在运行期间编辑方案，保存只影响下次；编辑页明确显示本次运行使用先前快照。关闭管理窗口仍不停止任务。
- 现阶段仍只运行一个根方案；多个账号在该根方案内部并行，不额外引入多套根调度器。

## 单账号默认日常

主面板优先提供所选账号的“运行日常 / 编辑日常”，多账号与其他方案折叠。每个账号第一次被启动器列出时生成一个默认日常，使用DefaultAccountId及“本账号”绑定稳定ID；名称可重名、可改，不复制密码。旧账号也补齐，删除后不自动重建，复制方案清除DefaultAccountId。

初始语句为“日常操作,本账号,待选择存档”。该占位参数在预校验中形成选档请求，正式编译仍拒绝它。首次运行弹出与游戏一致的两列四行1～8，先自动读取并更新八个名称，再显示选档卡片；已有首页窗口直接复用，已在存档中则退出后读取。选择直接替换源码中的存档参数，之后可手动编辑。

编译预览先校验完整调用树、绑定及并行交集，再按方案ID＋账号ID收集待选行；同一子方案重复调用只询问一次。全部确认后保存，取消任意一项不部分写回，已扫描的名称和窗口保留。正式编译使用替换后的源码，执行器不接受未配置编号。根方案及子方案均走这一入口，正在准备时也禁止重复开始。

默认结束保留窗口。初始化记录位于scripts/config/account-daily-created.json，不随更新清除；删除账号不擅自删除其可编辑方案。用户可以在脚本管理中清理或重用已失效账号的方案。
## 语句与绑定

切换未保存草稿前提供保存/不保存/取消；错误草稿仍可保存。插入操作时空白行原位复用，非空行在其后插入完整语句，避免拆开原参数。两个搜索栏右端均显示放大镜。

每行一条语句，英文逗号分隔，空行忽略；右侧表单可直接生成语句，用户也可手写。例如：

    日常操作,示例主号,存档5
    日常操作,示例主号,存档6
    关闭窗口,示例主号

“日常操作”封装进入目标存档、打开助理、选择内置日常、运行确认和完成观察，内部点击不暴露成十几条必填语句。关键字、参数个数、账号及存档在运行前校验，错误标到原始行。

- 中文账号名和存档1～8直接可用。账号重名时要求在选择器中明确绑定，不能默认挑第一条；显示名称不等于执行身份。
- 方案明文保存语句及稳定账号ID映射；同名账号有辅助标识。改名继续绑定原ID，删除后标记缺失，不自动转绑。
- 常量在参数面板定义为全局默认值或本方案覆盖值，并通过$名称引用，例如主号为账号别名、日常一为存档5、日常二为存档6。首版常量保存字符串，使用时按命令的账号/存档参数校验，不提供表达式求值。
- 包含逗号或引号的名称使用双引号包围，引号通过重复表示；不能直接对整行Split逗号。首版不为普通名称强制增加引号。
- 未来参数化子方案复用同一绑定机制；首次只提供无参的已配置方案调用，不要求用户学习另一套变量语法。

使用常量的同一示例：

    日常操作,$主号,$日常一
    日常操作,$主号,$日常二
    关闭窗口,$主号

## 首批启动器操作与窗口规则

| 语句 | 完成条件和窗口行为 |
|---|---|
| 读取存档名称,账号 | 确认完整两列四行卡片再读取八个名称，标题先于卡片出现时只重新观察等待；默认临时2倍速，完成保留窗口，可供本次方案继续使用 |
| 启动存档,账号,存档号 | 确认进入指定存档后结束本语句，不隐含启动日常或关窗 |
| 日常操作,账号,存档号 | 完整启动并等待内置日常结束；默认保留窗口，不重复手动保存 |
| 退出存档,账号 | 退出并确认，回到可点击“读取存档”的入口；不结束账号进程 |
| 关闭窗口,账号 | 仅关闭本次运行已取得控制权的精确账号窗口；账号下同时只可能有一个当前存档 |
| 调用,子方案名称 | 在同一个运行实例内执行已绑定子方案，等待它完成，沿用会话和停止状态 |

“关闭某个存档”容易混淆退出存档和关闭账号窗口，界面分别提供这两种操作。若以后支持带存档参数的关闭，必须核对当前存档，不能误关已经切换的窗口。

同账号多个日常存档默认复用窗口：前一个已确认完成并保存后，自动“退出存档→确定→读取存档”再进入下一个。账号整组完成后，用户可插入“关闭窗口”；不因编辑文本相邻而无条件关窗。

- 在同次运行内，子方案之间可以复用根运行实例持有的会话；子方案结束不自行释放窗口所有权。根运行结束后保留的窗口恢复原倍率和手动尺寸调整，并交还用户。
- 按稳定账号ID接管本面板已有窗口，包括普通启动及上次脚本保留窗口；不抢系统焦点，不扫描其他面板或按标题猜测。已有控制者尚未释放时等待空闲。日常切换到方案指定存档，已知同档直接复用。
- 接管时用户已选择切换至方案指定存档，因此可以退出接管前的当前档；同次脚本自动切档仍要求前一日常完成，不能补点保存。独立读取名称不擅自退出已有游戏，首次运行的名称扫描按接管规则退出。
- 真正的日常完成判定继续沿用本轮进度增长、N/N标题左侧绿勾持续至少3秒；读到旧完成画面不算本次完成。
- 扫描结果更新名称资料及编辑界面，不改变运行快照中的账号ID、存档号或执行顺序。

## 顺序、并行和子方案

普通语句严格从上往下执行；需要同时运行多个账号时显式插入“并行开始/并行结束”。用户已确认该规则，不沿用v1隐式按账号重排的行为。

主方案示例：

    并行开始
    调用,主号日常
    调用,小号日常
    并行结束

其中“主号日常”包含主号存档5、存档6及最后关闭窗口；“小号日常”包含另一个账号的存档1及关闭窗口。两个子方案并行，主号两个存档仍串行；并行结束等待所有分支完成。

- 并行块中的每行操作或子方案是一条分支。推荐使用子方案组织每个账号的多档任务；直接插入不同账号的独立操作也支持，同账号分支交集在编译时拒绝。
- 一个账号只有一份会话所有权。展开后发现两个并行分支使用相同账号时，校验明确提示合并为同一串行子方案，不通过交错点击“模拟并发”。
- 并发数限制同时执行的账号，不限制文本行数；默认不设固定账号上限。账号等待其他脚本释放控制权期间不占执行槽。
- 跨账号需要先后关系时写在并行块之外，或先等待并行块完成，不能依赖账号实际完成速度。
- 停止向所有分支和当前子方案传播，不再启动后续语句；游戏内置脚本可能继续。单账号异常保留现场，其他独立账号继续；失败分支不能视为成功跨过后续等待点。
- 一次启动冻结完整调用树。子方案引用稳定ID，改名保留关联；缺失引用和调用环在启动前报错。并行中同名显示不影响身份。

## 引用更新、保存与实现

- 方案改名后保存，勾选“同步更新所有已有引用”会按方案ID修改其他方案中对应调用语句及新名称绑定；未勾选时保留旧文字和原ID，不改绑到同名对象。
- 脚本窗口刷新账号时发现同一ID改名，勾选上述选项则同步已有方案及当前草稿中的账号引用；重名或别名冲突会提示，不覆盖已有绑定。
- 全局默认常量位于scripts/config/constants.txt，右栏单独校验并原子保存；所有方案及子方案均可引用。本方案同名值优先，旧常量仍为本方案覆盖值，不自动迁移或覆盖。编译器复制全局默认值后冻结完整树，后续修改不影响运行。保留相同值、只改本方案常量名称时，勾选同步会更新该方案中的$引用；全局改名需手动调整引用。
- 账号及子方案选择器对重名对象使用辅助ID别名；用户输入的别名已经绑定其他对象时拒绝覆盖。旧别名保留为兼容入口，稳定ID负责身份。
- 中文解析、常量/ID绑定及并行交集校验集中于Application/ScriptProgram，输出冻结的操作树；ScriptProgramRunner负责顺序、并行和根会话生命周期，ScriptCoordinator统一运行状态与停止。所有子方案共用一个根调度和视觉租用。
- UI和主面板共用ScriptWorkspace编译/运行入口；名称资料在scripts/catalog，与源码、运行状态分开。名称校正更新下一轮编译的显示信息，不改本次快照。
- 新方案version=2，明文保存source、accountBindings、planBindings和constants，不包含凭据。constantsSource额外保留未完成常量原文；保存/读取仅校验文档结构，编译才检查语句和常量。源码开头的“方案设置,子方案,是”和“方案设置,面板可见,否”优先同步isSubPlan及showOnDashboard；每项只能声明一次，必须在执行语句前。新方案默认不是子方案、面板可见；旧方案缺少声明时沿用原属性，isSubPlan默认true兼容既有调用。子方案可以独立运行；未设为子方案的对象不出现在调用选择器，编译也拒绝调用。isBuiltIn仅用于模板标记。v1可原样运行；日常方案可显式复制为顺序语句，用户再安排并行。旧版自定义视觉方案可继续运行，首版不把它误转换成日常。
- 主包更新合并默认资源，保留正常安装目录的plans、config、catalog及自定义脚本。开发包内测试方案按用户要求，清理过期包时无需备份。
