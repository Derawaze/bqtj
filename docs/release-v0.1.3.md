## 使用与验证

下载 ZIP 并完整解压，运行 BqtjLauncher.Desktop.exe。已包含 .NET；仍需本机注册32位 Flash ActiveX。账号密码按用户选择明文保存在本机。

开发包构建、格式检查及面板显示检查通过。自动测试与发行构建结果以本标签 GitHub Actions 为准。

加载蓝色闪帧仍保留观察；战斗点击、跨屏 DPI 和长时游戏未作本轮验收。不承诺 Flash 全部本地存储隔离。
