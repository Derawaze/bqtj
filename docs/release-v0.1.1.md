## 本版改动

- 游戏入口由运行时解析：读取4399官方游戏页当前发布的包装页地址，只接受HTTPS、4399主机、`upload_swf`下版本化文件；官方给的`sda`主机对无Referer请求返回错误页，因此换到同路径可直连主机后再交给原生宿主。
- 回退顺序：官方页 → 上次成功解析的缓存（`%LOCALAPPDATA%/BqtjLauncher/game-page.json`）→ 随包兜底地址；三条路径都不抛异常，断网仍可启动。
- 面板状态显示当前版本与来源（平台最新／使用缓存版本／兜底版本）。
- 原生登录来源门禁改为按来源和路径前缀匹配，不再绑定具体版本文件名，避免版本更新后自动登录静默失效。

## 验证范围

- 61项.NET测试通过（新增11项覆盖解析、镜像映射、缓存与回退）。
- 实机网络探针用生产类解析到 `OfficialPage / 3690g`，回读包装页确认指向 `v3690.swf`（4.39 MB，2026-09-22更新）。
- 发布包复核通过：4文件白名单、单一版本化根目录、两个入口均为 x86 PE（Machine=0x014C）、ZIP名与SHA256一致。
- 本轮原生宿主已用32位MinGW-w64 GCC重新编译（117,248字节，x86 PE），包含登录门禁改动。
- 待用户验收：面板启动后显示“平台最新”，游戏为新版本；自动登录在新包装页的实际结果；第二账号并行不串号。

## 构建环境备注

`tools/Publish-Release.ps1`、`tools/Build-NativeFlashHost.ps1`、`tools/Test-ReleasePackage.ps1` 以 UTF-8 无 BOM 保存且含中文串，在 Windows PowerShell 5.1 配非 UTF-8 代码页时无法解析（中文串被误读后破坏标记）。本轮按脚本内等价步骤直接执行 `gcc` 与 `dotnet publish` 并复核。修复这三个脚本的编码（加 BOM 或改用 pwsh 7）属于后续独立改动，未在本轮进行。
