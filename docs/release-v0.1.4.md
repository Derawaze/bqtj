# v0.1.4

- 面板启动时自动检查启动器更新，右上角支持手动检查；底部显示结果并链接到对应 GitHub 发布页，用户查看说明后自行下载。
- 修复退出清理等待界面线程导致的后台进程残留；覆盖正常退出、5秒超时终止和整层会话释放的回归测试。
- 包含此前已验收的 F3 最近变速修复、容器启动分阶段超时与重试。
- 规范开发包与正式包目录、版本号和人工验收门槛，避免开发迭代占用正式版本及覆盖已有产物。

## 使用

完整解压 ZIP 后运行 BqtjLauncher.Desktop.exe，两个 EXE 必须放在同一目录。已含 .NET；游戏仍需本机注册32位 Flash ActiveX。账号密码按用户选择明文保存在本机。更新检查只打开发布页，不自动下载安装。

## 验证与限制

用户于2026-09-28指示提交、推送并正式发布当前成功版本。发布测试及构建结果见本标签 GitHub Actions。

- 文字操作曾报告卡在“语法判断中”，用户目前暂未复现；本版未宣称修复该问题。
- 加载蓝闪、跨屏 DPI、长时运行继续按实际反馈观察。
- 不承诺 Flash 全部本地存储隔离，关闭游戏后可用已保存凭据重新登录。
