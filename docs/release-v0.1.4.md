# v0.1.4 热更新（F3 最近变速在游戏中失效）

日期：2026-09-26。本轮修复 F3「最近变速」快捷键在游戏中不生效的问题，先交付热更新包，待用户实机验收后再决定是否出完整发行包。

## 缺陷与根因

现象：进入游戏后不先点一下游戏画面，按 F3 没有任何反应；点击过游戏画面后 F3 才可用。

原因：F3 只由面板容器的 WPF 窗口 `PreviewKeyDown` 处理。游戏画面是独立的原生宿主进程里的 `Shell.Explorer.2` / Flash 子窗口；用户一点击游戏画面，键盘焦点就转移到该子窗口，按键不再回到 WPF 窗口，于是快捷键静默失效。焦点在工具栏时（加载完成后的默认状态）才能触发，所以表现为“有时要先点一下”。

## 改动

- 原生宿主启用宿主线程内的 `WH_GETMESSAGE` 钩子，在消息分发前截获 `WM_KEYDOWN` 的 F3：吞掉按键（避免同时触发页面自身行为）并通过既有控制管道上报 `recent-speed-key`。
- 按住 F3 只在首次按下上报一次，抬起后复位，避免连续跳档。
- .NET 侧控制器把该事件行与命令回执区分开：读到事件就回调，命令等待继续读下一行，因此事件不会打乱变速/刷新/显示的回执时序。
- 面板容器订阅事件并切回 UI 线程执行原有的档位互换；焦点在 WPF 窗口时仍走原来的 `PreviewKeyDown`。
- 新增原生探针 `native/Diagnostics/RecentSpeedKeyProbe.c`：验证 F3 恰好上报一次、抬起不重复上报、连按两次各上报一次、其它按键不上报。
