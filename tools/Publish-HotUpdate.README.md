# 爆枪突击启动器 热更新 v{{VERSION}}

本包只包含被替换的两个程序文件，用于覆盖到你已经解压好的启动器目录。

## 覆盖步骤

1. 先关闭所有正在运行的启动器面板和游戏窗口（任务栏里不能残留）。
2. 把本包内的两个文件复制到启动器目录，覆盖同名旧文件：
   - `BqtjLauncher.Desktop.exe`
   - `BqtjNativeFlashHost.exe`
3. 重新运行 `BqtjLauncher.Desktop.exe`。

不需要删除账号数据、不需要重新解压完整包；`%LOCALAPPDATA%\BqtjLauncher` 下的账号、凭据和偏好都会保留。

## 本包内容

- 修复 F3「最近变速」在游戏中按了没反应：焦点落到游戏画面（Flash 子窗口）时按键不再回到面板，只有先点一下游戏画面才生效。现在由原生游戏宿主在自己的消息循环里截获 F3 并通知面板，焦点在哪都能互换档位。
- 修复/加固容器启动：宿主在耗时初始化前先上报启动阶段，面板据此区分“宿主没起来”和“IE/Flash 初始化慢”，等待上限从固定 10 秒放宽到 45 秒；首次确实卡住时会自动重启一次宿主再继续，而不是直接报错退出。
- 启动过程（宿主 pid、启动阶段、耗时、退出码与 stderr）会写入 `%LOCALAPPDATA%\BqtjLauncher\logs`，便于定位现场问题。

## 验收要点

1. 启动账号能正常进入游戏，不再出现“启动器初始化失败，操作超时”。
2. 进入游戏后**不点击游戏画面**直接按 F3，应在当前档位与上一档之间互换（变速按钮提示会更新）。
3. 点击游戏画面后再按 F3，仍然可以互换。
4. 按住 F3 不会连续跳档；切到别的窗口再切回游戏，F3 仍然有效。

如果第 1 条仍失败，请把 `%LOCALAPPDATA%\BqtjLauncher\logs` 下当天的日志发回；日志现在会记录宿主启动到了哪个阶段。
