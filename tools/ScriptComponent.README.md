# 脚本视觉组件

将组件ZIP直接解压到包含 BqtjLauncher.Desktop.exe 的目录，形成 components/automation/BqtjScriptVision.exe。ZIP根只有components目录，没有外层版本目录；“全部解压”目标选主程序目录，不新建组件包同名目录。不需要安装Python、Lua、额外.NET或VC运行库。

日常和读取存档兼容协议2，当前天空顶刷材料需要协议7组件，包含N/W同步输入和蓝/绿色限额计数识别。请配套更新主包及组件；旧组件会在刷关前提示更新。先停止队列并退出启动器，再覆盖components目录。

组件使用64位Windows上的MaaFramework 5.14.2和中文PP-OCRv4模型，只支持CPU推理；主启动器继续使用x86，未运行脚本时不加载视觉组件。

在主面板打开“管理脚本”，左侧复制模板或新建方案，中间编辑中文语句，右侧选择命令和账号/存档后插入。保存后右侧切换运行监控；点“编辑方案”重新修改。常用语句为日常操作、读取存档名称、启动存档、退出存档、关闭窗口及调用子方案。

普通语句顺序执行，“并行开始/并行结束”让不同账号的子方案并行；同账号多个存档放在一个串行子方案中复用窗口，最后显式关闭窗口。读取存档名称默认临时2倍速、成功保留窗口，同次方案可以继续使用；单独读取结束后再启动另一方案，应先关闭已交还用户的窗口。名称资料可手动校正，低置信度结果提示复核。

刷取每日材料默认天空顶、正常、地狱四、临时2倍速。战后关闭AI，先上后右，按截图确认碰到边界便结束该段；输入时长只作上限。搜索途中看见宝石或图鉴就提前转入拾取，仅处理当前可见区域。刷满仅第10轮起且通关首屏无材料时查双限额，两项都满才退出；有材料先捡，不在拾取后追加检查，固定次数不查。必需材料为冷冻宝石、守护宝石及冥王图鉴，血石只辅助邻近掉落区定位，三宝箱及装备顺带；失败保留窗口。

脚本运行及存档读取期间固定100%的950×600画面，禁用窗口大小菜单、最大化及拖拽缩放。结束、停止或异常后保留的窗口解除尺寸锁，不修改共享窗口偏好。可以遮挡，不占用系统鼠标；最小化时暂停识别，恢复后继续观察。关键点击回执不确定时暂停，不自动重复。

冷却等待及最终保存由游戏内置脚本完成；外部只观察本次进度增长及整体N/N标题左侧绿色勾持续至少3秒，不补点保存。“停止队列”只停止外部操作，内置脚本可能仍在运行；失败时保留窗口供人工处理。

请先停止队列再替换组件，不删除用户 scripts/plans/。运行时不自动下载依赖或安装系统组件。

本轮组件保持协议7格式，新增截图前及截图等待期间刷新后台悬停；只维护当前目标，一秒短租期，点击、走位或释放目标立即清除，不拉动系统鼠标。需与本轮主程序一起更新。两种账号权益都从第10轮起允许查限额，连续空屏不再触发刷满退出；有总统保持AI并等约1秒自动拾取，无总统使用固定扫顶及局部路线。

MaaFramework保持动态链接，来源及许可证见THIRD_PARTY_NOTICES.md、licenses/和模型目录README。视觉进程源码在native/ScriptVision，构建命令见项目开发手册。
