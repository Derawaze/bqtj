# 爆枪突击启动器

用于 Windows 的《爆枪突击》桌面启动器，方便管理账号、启动游戏和运行日常。

- 单账号直接使用，也支持多个独立游戏窗口。
- 新增、编辑账号，本地保存账号密码，启动时自动填充并登录。
- 账号管理工具支持搜索、原位编辑、多选删除及 TXT 导入导出，重复账号由用户审核。
- 脚本管理支持JSON脚本包、账号存档方案和官方日常的后台执行；视觉组件独立提供。
- 支持游戏刷新、静音、窗口缩放、全屏和等比例居中。
- 支持本地播放变速，按 F3 切换上一档速度。
- 支持检查更新、打开日志目录和导出脱敏诊断包。

解压发行包后运行 `BqtjLauncher.Desktop.exe`，三个 EXE 请放在同一目录。双击 `BqtjAccountTool.exe` 可独立打开“账号管理工具”；面板“管理账号”按钮和新增/编辑弹窗的“打开批量管理工具”均可进入，已有窗口会直接唤起。自带 .NET，运行游戏仍需本机已安装并注册的 32 位 Flash ActiveX。

账号管理工具左栏显示名称与账号，密码默认隐藏，勾选“显示密码”后显示密码列；支持按名称/账号搜索。双击或右键单元格原位编辑，Enter 保存、Esc 取消，已保存的密码留空仍沿用旧值。勾选行或按 Ctrl/Shift 多选后可以批量删除，全选仅作用于当前搜索结果；切换搜索条件会清空选择。右栏用于批量导入及导出。
批量 TXT 每行格式为 `名称 账号 密码`，三项以空格分隔且不能包含空白。名称可以重复，4399账号唯一；重复项默认填入新数据，点击“替换原记录”才更新，也可手动修改、跳过或稍后审核。其他记录继续导入。导出文件包含明文密码，仅导出已保存账号密码的记录。

新增账号的账号和密码可以同时留空，供游戏内手动登录；编辑已有凭据时，密码框留空表示沿用原密码，删除保存信息需勾选“清除”。

账号密码按用户选择，以明文保存在当前 Windows 用户的 `%LOCALAPPDATA%\BqtjLauncher\launcher.db`（SQLite 数据库，通常为 `C:\Users\<用户名>\AppData\Local\BqtjLauncher\launcher.db`）。在资源管理器地址栏输入 `%LOCALAPPDATA%\BqtjLauncher` 即可打开所在目录。验证码或登录错误需手动处理。本软件为第三方工具，与游戏运营方无隶属关系。

## 脚本与官方日常

将独立视觉组件包直接解压到包含 BqtjLauncher.Desktop.exe 的目录，形成 components/automation/BqtjScriptVision.exe。ZIP根目录就是components，不带外层版本文件夹；使用“全部解压”时将目标选为主程序目录，不要再创建组件包同名目录。存档识别需要协议2组件，已安装的协议2组件可沿用；仅更新本轮编辑器无需更换视觉组件，旧协议会在启动识别前提示更新。首版视觉组件支持64位Windows，使用共享CPU OCR进程，不要求另装.NET、Python或Lua；未运行脚本时不加载组件。

每个新建或导入的账号会附带一份可编辑日常；已有账号首次使用此功能也会补齐。主面板右侧以“当前账号日常”为主要入口，点击“运行日常”，第一次自动读取并更新八个存档名称，再用两列四行卡片选择存档1～8，选择会写回脚本，之后一键运行；“编辑日常”可继续修改。取消选择保留扫描窗口及名称缓存，不改写存档号。默认结束保留窗口；需要关窗可在语句末尾添加“关闭窗口,本账号”。删除自带日常后不会自动重建，账号改名不改变ID绑定。

准备选档期间点击停止，迟到的选择结果不会写回方案。日常可以接管本面板已有的游戏窗口，退出当前档后切换到方案指定档。

其他可见方案和多账号组合放在“其他方案 / 多账号”折叠区，不要求使用并行。账号日常也能作为子方案，首次运行先收集所有待选存档，全部确认后才保存并启动。
在主面板点“管理脚本”打开独立编辑器：左侧统一显示全部方案，内置方案名称后标记“（内置模板）”，可直接编辑或复制；中间编辑中文语句，右侧选择操作、账号和存档后插入，双击命令也可插入；当前行为空时原位插入，非空则插入下一行。每行一条语句，参数用英文逗号分隔；支持命令高亮、行号、校验、常量和已保存子方案调用。账号重名时从选择器明确绑定，实际身份仍为账号ID＋存档号。

例如一个账号连续运行两个存档，最后关窗：

    日常操作,示例主号,存档5
    日常操作,示例主号,存档6
    关闭窗口,示例主号

“日常操作”包含进入目标存档、打开助理、选择游戏内置“日常操作复制”、运行确认和完成观察。最终冷却及保存完全由游戏执行，启动器不补点保存；观察本次进度增长、整体N/N标题左侧绿勾持续至少3秒后才认定完成。默认保留窗口，同账号下一存档自动退出并切换；只在显式“关闭窗口”时关窗。

普通语句从上到下执行。右侧插入已保存子方案，需要多账号同时执行时使用：

    并行开始
    调用,主号日常
    调用,小号日常
    并行结束

并行块等待所有分支完成；同账号的多个存档放进同一个串行子方案，两个并行分支使用同一账号会在运行前报错。并发数0不限制，可按电脑资源降低；默认临时2倍速，不覆盖用户偏好。按账号接管本面板已有窗口（含“启动存档”保留窗口），切换到方案指定存档；同一窗口只能由一个脚本控制；所有子方案共享同一个运行实例和会话。

其他操作为“读取存档名称,账号”“启动存档,账号,存档号”“退出存档,账号”。读取名称默认2倍速、完成保留选档窗口，同次方案可以继续运行日常；独立扫描结束后窗口交还用户，再运行其他方案前应先关闭它。选档标题出现后会等待完整两列四行卡片，再识别名称或选档；等待只重新观察，持续未匹配保留窗口。名称资料在scripts/catalog/，选择存档后可手动校正，低置信度项提示复核；名称更新不改变本次运行快照。显式退出不会替用户补点保存。

常量是给常用值起别名，可选、可以留空。右侧“全局默认值”填写日常档=存档5并点击“保存全局常量”，所有方案及子方案均可用$日常档；保存在scripts/config/constants.txt。“本方案覆盖”随方案保存，同名值优先于全局值；已有方案的常量仍保留为本方案覆盖值，不会被全局配置覆盖。每行填写一个“名称=值”，全局配置格式有误时不会替换原文件。改名时可勾选“同步更新所有已有引用”；账号和子方案保留稳定ID，未同步的旧别名仍指向原对象，不会改绑同名对象。运行中编辑只影响下一次。名称包含英文逗号时用双引号包围，名称内双引号重复书写。

语句或常量未写完、校验未通过也可以保存草稿并保留原文；运行时必须校验通过，失败不会启动游戏。切换、新建或复制前若有未保存修改，会询问是否保存；可保存后继续、不保存继续或取消切换。关闭窗口只隐藏并保留草稿。保存后右侧命令栏收起并切换运行监控，中间显示只读语句；双击方案、双击编辑区，或点击底部“校验语句”左侧的“编辑方案”均可编辑。监控明确显示本次运行方案和逐条结果，不能编辑当前队列。编辑时右下角只显示“插入语句”，切换运行监控后同一位置显示“停止本次运行”。“停止本次运行”只停止外部操作，游戏内置脚本可能仍运行；异常保留现场，其他独立分支继续。在脚本开头声明“方案设置,子方案,是”和“方案设置,面板可见,否”。子方案可被调用，也可独立运行；面板可见性单独控制快捷下拉框，不决定调用权限。新方案默认不是子方案、默认面板可见；没有声明的旧方案沿用原属性且默认可被调用。声明必须放在执行语句前，每项只能出现一次。内置模板默认不显示。

游戏窗口在运行期间固定100%的950×600画面，禁用窗口大小菜单、最大化及拖拽缩放；结束、停止或异常后保留窗口恢复原倍率和尺寸调整，不修改共享偏好。窗口可以遮挡，但不能最小化；最小化暂停观察，恢复后继续，不重复关键点击。关闭脚本管理窗口不停止任务，退出主启动器仍按原规则关闭游戏。

内置模板为“单账号多档日常”“并行调用两个子方案”和“全局常量示例”，方案设置与日常操作说明在模板注释中。读取名称操作仍可插入，单独读取名称的内置模板已移除。模板和用户方案同在scripts/plans/；升级补说明、保留已编辑内容，不恢复已删除模板。请保留.built-ins-v1、.built-ins-v2及scripts/config/中的初始化记录。

新版方案使用version=2，已有v1方案仍按原账号并行、逐项关窗规则运行。v1日常可复制为中文顺序语句后自行安排并行；旧版自定义JSON脚本方案暂不自动转换为日常语句。

同目录 scripts/ 接纳JSON文件或含 script.json 的脚本目录，自动识别但不会自动执行。用户方案明文保存在 scripts/plans/，不含账号密码；存档名称资料在scripts/catalog/。更新前退出启动器，将新包文件合并覆盖到旧程序目录，保留此目录及用户脚本；不要先删除整个scripts目录。搬到新目录时先复制旧scripts目录，再合并新包的默认脚本，让用户方案、全局常量、名称资料及自定义脚本保留，官方文件更新。默认脚本及JSON格式说明见包内 scripts/README.md。
