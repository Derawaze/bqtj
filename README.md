# 爆枪突击启动器

用于 Windows 的《爆枪突击》桌面启动器，方便管理账号、启动游戏和运行脚本。

- 单账号直接使用，也支持多个独立窗口，不设固定多开数量上限。
- 本地保存账号，启动时自动填充登录；验证码和登录错误由用户处理。
- 独立账号管理工具支持搜索、原位编辑、多选删除、TXT导入导出和重复审核。
- 中文脚本编辑器支持日常、多档顺序执行、子方案和多账号并行。
- 支持刷新、静音、窗口缩放、全屏和本地变速，F3切换上一档速度。
- 提供更新检查、日志目录和脱敏诊断包导出。

## 启动与账号

解压后运行 `BqtjLauncher.Desktop.exe`，三个EXE放在同一目录。自带.NET，游戏仍需本机安装并注册32位Flash ActiveX。多账号按电脑资源选择并发量，同一个账号记录只打开一个窗口。

双击 `BqtjAccountTool.exe` 可独立打开账号管理工具；主面板“管理账号”和新增/编辑弹窗中的“打开批量管理工具”也会唤起同一个工具窗口。密码默认隐藏，勾选“显示密码”后可查看和编辑。双击或右键单元格进入编辑，Enter保存、Esc取消；支持名称/账号搜索，Ctrl/Shift多选和批量删除，全选只作用于当前搜索结果。

批量TXT每行写一组，三项用空格分隔，名称、账号、密码本身不能含空白：

```text
示例主号 example_user_1 example_password_1
示例小号 example_user_2 example_password_2
```

名称可以重复，4399账号唯一。重复项只进入人工审核，点击“替换原记录”才覆盖，其他行继续导入；也可修改、跳过或稍后审核。导出含明文密码，只导出已保存凭据的记录。新增账号可将账号和密码同时留空，供手动登录；编辑时密码留空沿用旧密码，勾选“清除”才删除保存信息。

账号密码按用户选择，以明文保存在当前Windows用户的 `%LOCALAPPDATA%\BqtjLauncher\launcher.db`（SQLite，通常为 `C:\Users\<用户名>\AppData\Local\BqtjLauncher\launcher.db`）。在资源管理器地址栏输入 `%LOCALAPPDATA%\BqtjLauncher` 即可打开所在目录。

## 脚本与官方日常

视觉组件支持64位Windows。将组件ZIP直接解压到主程序目录，得到 `components/automation/BqtjScriptVision.exe`；不要再套一层组件包名称。日常和读名兼容协议2组件，材料刷关需要协议7及配套资源。组件按需加载，共用一个CPU识别进程和中文模型，不要求另装.NET、Python或Lua。

每个账号附带一份可编辑日常。第一次“运行日常”会读取八个存档名称，再按两列四行选择存档；选择写入方案，之后一键运行。取消保留已读取名称和窗口，不改写存档号。默认结束保留窗口，删除这份日常后不会自动重建。

“管理脚本”打开独立窗口：左侧选方案，中间编辑中文语句，右侧双击插入命令；保存后右侧切换为运行监控。内置模板可直接编辑或复制，与用户方案一起保存。每行一条语句，以英文逗号分隔参数，例如：

```text
日常操作,示例主号,存档5
日常操作,示例主号,存档6
关闭窗口,示例主号
```

日常优先选择游戏内“日常操作复制”，其次“日常操作”；第四项可指定准确名称，例如 `日常操作,示例主号,存档5,我的日常`。冷却和最终保存由游戏内脚本执行，启动器只观察本次进度变化及持续3秒的完成绿勾。下一条同档操作直接复用窗口，换档才退出切换；日常负责收起自己的系统页和侧栏。

全局常量、子方案、并行块、引用更新和草稿保存见[脚本说明](docs/script-composition.md)，包内也附有 `scripts/README.md`。普通语句顺序执行，多账号并行需显式安排，同账号不同存档串行。账号实际绑定稳定ID，改名不改变身份。

运行默认临时2倍速，画面固定100%的950×600，暂时禁用缩放。窗口可以被遮挡，不能最小化；恢复后重新观察。暂停保留当前步骤，停止/异常后继续使用本次快照重试未完成语句，刷关次数重新计数；继续记录只在本次进程有效。关闭脚本管理窗口不停止任务，停止外部操作后游戏内脚本或AI可能仍在运行。

## 天空顶每日材料

当前开发分支的天空顶脚本已由用户确认为初代可用版本，正式版仍为v0.1.5。使用“启动存档”指定账号/存档后，可插入：

```text
启动存档,示例主号,存档5
刷取每日材料,天空顶,地狱四,刷满
```

最后一项也可写正整数次数，例如 `8次`。无总统时先向上、再沿顶向右搜索，发现必需材料后进行局部拾取；满包时整理武器、装备，基因体满时才分解，沿用游戏当前筛选条件。装备详情遮挡时会后台移开悬停再观察。

新增/编辑账号和账号工具可设置“有总统（月卡）”，账号所有存档共用、默认关闭。总统模式通关后等待约1秒自动拾取，不走位或拆解。续费或到期后手动调整设置，下次运行生效；三字段TXT不改变已有权益。

**每日限额识别仍待改进。** 刷满从第10轮起查询，冷冻宝石/守护宝石共享限额和冥王图鉴限额都达标且为绿色才结束；读不到或连续空屏不会推断已满。需要明确控制轮数时可使用次数模式。流程、资源规则和验证边界见[材料刷取](docs/sky-top-materials.md)，待办见[任务清单](docs/backlog.md)。苍木道等其他关卡尚未开放。

## 更新与本地文件

退出启动器后，将新包合并覆盖到旧目录。保留整个用户脚本目录，不要先删除 `scripts/`；换目录时先复制旧scripts，再合并新版官方文件。

| 位置 | 内容 |
|---|---|
| `scripts/plans/` | 用户方案和可编辑模板，不含账号密码 |
| `scripts/config/` | 全局常量、默认日常初始化记录 |
| `scripts/catalog/` | 已读取及校正的存档名称 |
| `scripts/resources/loot/` | 官方掉落图标和按关卡/用途选择的识别规则 |
| `components/automation/` | 可选视觉组件及模型 |

官方脚本资源和视觉组件可分别合并更新，保留用户方案；新增语法或底层能力可能仍需更新主程序。修改文字的位置与预览方式见[界面文案指南](docs/ui-text-editing.md)。

主面板可打开 `%LOCALAPPDATA%\BqtjLauncher\logs` 或导出脱敏诊断包。脚本日志 `script-日期.jsonl` 只记录固定菜单、坐标、回执和状态，不记录账号密码、方案原文、任意OCR或截图；按天及2MiB滚动，最多7份。
