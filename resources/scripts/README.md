# 脚本目录

将单个 JSON 文件或含 script.json 的脚本目录放到这里，脚本管理窗口会自动发现，不会自动运行。

用户方案保存在 plans/，明文记录账号 ID、存档号和名称、排序、倍率、并发数及关窗选项，不含账号密码。覆盖更新请保留 plans/ 和自己添加的脚本。

每个账号自带的日常默认绑定“本账号”的稳定ID；首次运行自动读取并更新八个名称，再选择两列四行中的存档，待选择存档会直接改写为存档1～存档8。之后可以编辑源码，取消保留扫描名称和窗口，不改写方案；作为子方案时也先完成选择。初始化记录在config/account-daily-created.json，删除自带日常后不重新生成。复制日常成为普通方案，不占用账号默认入口。

新版编辑器将中文语句及绑定保存为plans/中的version=2方案。每行一条操作、英文逗号分隔参数，支持日常操作、读取存档名称、启动存档、退出存档、关闭窗口、调用及并行开始/并行结束。普通语句顺序执行；同账号多存档放进同一个子方案，不同账号子方案可显式并行。读取名称完成保留窗口，日常接管本面板已有窗口并切换到指定档；结束时不自动关窗，需要时插入“关闭窗口,账号”。

全局常量在config/constants.txt，右栏编辑后单独保存，所有方案及子方案均可使用；本方案同名覆盖值随方案保存并优先。常量可选、可留空；每行“名称=值”，例如日常档=存档5，语句中以$日常档引用，修改一处即可复用。已有方案的常量保留为本方案覆盖值，需留空才采用同名全局值。账号/子方案通过稳定ID绑定，改名可选择同步所有引用；运行时冻结完整调用树，编辑只影响下次。旧v1方案仍保留原语义，日常可复制为新版顺序语句。

语句或常量有错误也可保存，原文保留，运行前才强制校验。在脚本开头声明“方案设置,子方案,是”和“方案设置,面板可见,否”，分别决定能否被调用及主面板可见性；子方案仍可单独运行。声明在所有操作前且不得重复。没有声明的旧方案沿用showOnDashboard，isSubPlan默认true兼容旧调用；新方案默认不是子方案、面板可见。

内置模板与用户方案统一保存在plans/，可直接编辑，名称后有“（内置模板）”。内置为单账号多档日常、并行调用两个子方案、全局常量示例；读取名称的单独内置模板退役，操作本身仍保留。方案设置和日常操作说明在注释中。保留.built-ins-v1/.built-ins-v2标记；升级保留已编辑内容，不恢复删除。草稿的常量原文保存在constantsSource，旧方案的constants字典仍可读取。

存档显示资料保存在catalog/，读取后可以校正，名称不参与实际选档身份。覆盖更新保留plans/、config/、catalog/及自定义脚本；开发验收包内测试方案清理时无需备份。游戏窗口可以遮挡，但不能最小化。

默认脚本调用游戏内置的“日常操作复制”。最终保存由游戏脚本完成，启动器观察本次进度增长，再确认右侧整体N/N标题左侧绿色勾持续至少3秒；列表末行可以不在视口内，不能用画面静止代替完成判断。

JSON 使用 version: 1，id 是唯一脚本标识，name 是显示名称，entry 指向 flow 内的起始步骤 ID；步骤按数组顺序执行。

支持的步骤：officialDaily、enterSave、waitText、clickText、waitImage、clickImage、click、wait、waitOfficialCompletion。

- 文字步骤使用 text；图片步骤使用包内相对路径 image。
- roi 为 [x, y, 宽, 高]，默认整个950×600画面。click 使用 x、y；识别点击可附加 offsetX、offsetY。
- 界面等待默认 timeoutSeconds: 120；wait 使用 milliseconds，默认1000。
- enterSave 进入方案指定存档；officialDaily 包含选档、打开助理、启动日常与最终保存观察。
- waitOfficialCompletion 必须实际观察到本次日常进度增长，再持续确认最终保存；不能观察一个已经结束的旧画面直接完成。

标题先出现而卡片尚未绘制完整时，会等待完整八张卡片再识别或选档，期间不重复点击；持续不匹配保留窗口。识别失败或窗口不可用时保留游戏供人工处理；“停止队列”只停止启动器的外部操作，内置脚本可能仍继续运行。
