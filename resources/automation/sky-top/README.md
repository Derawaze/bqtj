# 天空顶识别图标

图标来自用户授权的游戏背包与战后现场，名称通过搜索、悬停说明和用户确认核对。只保存物品本体，不保存账号、角色名、背包数量或完整现场。catalog.json version=3既是素材索引，也是运行时的关卡/用途拾取规则；交付到scripts/resources/loot，与scripts/catalog的存档名称资料无关。

普通物品沿用背包图案；衣服、枪械使用单独的掉落图案。战场模板用透明遮罩排除品质光芒和相邻材料，不能直接拿整块发光区域当物品。首次模板/SIFT对背包截图的尝试不稳定，目前由共享像素截图上的本体图案与晶面分类提供开发识别。

衣服光芒从白、绿、蓝、紫、橙到红，枪械还可能有黑色品质光芒；本轮只认本体，不识别品质等级。装备与宝箱可以沿材料路线顺带捡走，不为它们绕路，不作为完成硬条件。银币、绿色弹药箱和补给光效不进入拾取清单。

2026-10-20：当前战场圈定分类已获用户确认，背包新增材料与副手/装置已悬停核对。回归覆盖三把相邻枪械、七种枪械背景光色、材料/宝箱拾取属性，以及蓝色装置不会变成冷冻宝石。背包图标回放不代表真实遮挡或完整拾取已验收，后续继续用战后现场验证。

月刺与屠夫的对应已纠正：宽刀为屠夫，细长刃为月刺。血石只辅助邻近掉落区定位，三种宝箱仍为全关卡顺带项。

小雨现场暴露了堆叠材料的漏识别：原守护宝石模板缺少战场可见样式，图鉴匹配也随物品浮动变化。新增两类物品的本体遮罩，各保留两个清晰度相位，覆盖浮动时的像素插值；只保留物品纹理，不把邻居、雨线、光晕并入。沿用0.88匹配门槛，匿名连续12帧及同场天空/出口反例用于回放；这不等于大雨或所有天气已验证。

冷冻宝石现在先匹配完整图标或战场本体纹理，门槛仍为0.88；青色连通群只有包含已匹配本体才会扩展为堆叠范围，不能仅凭颜色和硬边产生目标。cold-body-battle.png来自用户已确认的长条宝石堆，遮罩去掉相邻枪械和光晕。185326保留现场中，蓝色圆形装置及出口光效确实触发了旧晶面规则；本轮已用真实反例回放，不再把它们当宝石。扩大模板应补充物品本体信息，而非放大PNG或放宽颜色。

061142又遇到大簇守护宝石漏识别：旧本体样式不能覆盖被血石分隔的扇形堆叠，导致有宝石时清单仍为空。guard-pile-battle.png来自该现场露出的宝石本体，透明区域排除血石、旁边装置和外圈光晕。原阈值0.88及颜色预筛选不变，同一诊断程序仅换资源后原六帧全部识别，相关度约0.97～1.00。完整拾取仍待实机验收，不能把静态识别写成材料已捡完。

详细流程见[天空顶材料](../../../docs/sky-top-materials.md)。

三种宝箱登记在globalPickup，地图专用材料在profiles/map＋purpose的pickup中；recognize决定本关需区分的图案，不汇总其他关卡全部物品。图片与规则可单独覆盖，下一次运行生效，已运行任务使用快照。当前共37张PNG，弹药箱另有战场本体遮罩ammo-box-battle.png，用于排除补给并帮助镜头配准。新增guard-overlap-battle.png与hades-overlap-battle.png覆盖另一簇被血石/枪械遮挡的本体；匿名两帧旧版无目标、新版两类均命中，阈值仍为0.88。此次局部路线和限额计数另需更新主程序及协议7组件；单独只换图案可用于061142以后的本体识别版本。
